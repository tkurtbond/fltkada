function Create
       (Values : in Header;
        Colors : in Color_Definition_Array;
        Pixels : in Pixmap_Data)
    return Pixmap
with Pre =>
    Colors'Length = Values.Colors and
    Pixels'Length (1) = Values.Height and
    (for all Definition of Colors =>
        Ada.Strings.Unbounded.Length (Definition.Name) = Values.Per_Pixel) and
    Pixels'Length (2) = Values.Width * Values.Per_Pixel;

A colour given by name ("red") is read only on X11; on Wayland it is FLTK's gray. Give colours as "#rrggbb" (pofltk 47).

Raises Constraint_Error, in a release build too, if the data doesn't match the header, or the pixmap is too big for FLTK (FLTKAda-BUGS.md 77).
