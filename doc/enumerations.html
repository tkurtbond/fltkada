Fl_Boxtype Box_Kind

FLTKAda defines every box type when it starts, so Round_Up_Box, Shadow_Box, Plastic_Up_Box and the rest draw as themselves, not as an up, border or flat box (pofltk 8).
Fl_Font Font_Kind

An integer type, FLTK's font number, not an enumeration: Helvetica to Zapf_Dingbats and Free_Font are constants, and FLTK.Static.Setup_Fonts and Set_Font_Kind add fonts up to FLTK.Static.Last_Font. A font past Last_Font raises Constraint_Error (FLTKAda-BUGS.md 88, pofltk 130).

Fl_Labeltype Label_Kind

Shadow_Label, Engraved_Label and Embossed_Label are defined when FLTKAda starts (pofltk 8). Multi_Label, Icon_Label and Image_Label are left undefined, and draw nothing: FLTK would read a plain text label as a pointer for them.
