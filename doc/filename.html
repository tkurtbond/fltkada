The binding expands the name itself. fl_filename_expand aborts when a value doesn't fit, and never ends when a value names itself (pofltk 120). Each value goes in once, and the result is cut short to Max_Path_Length - 1 characters.

int fl_filename_isdir(const char *name);

function Is_Directory
       (Name : in String)
    return Boolean;

Name may be longer than Max_Path_Length. The binding calls stat itself: fl_filename_isdir copies a name ending in a slash into a buffer of FL_PATH_MAX bytes, which a longer name overruns (pofltk 121).

int fl_filename_match(const char *name, const char *pattern);

function Match
       (Input, Pattern : in String)
    return Boolean;

A pattern may leave a bracket or a brace open. fl_filename_match would read past its end (pofltk 122), so the binding passes it copies with NULs after them.
