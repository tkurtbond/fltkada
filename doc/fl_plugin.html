Package name
Fl_Plugin.H FLTK.Environment.Plugins

Note:

A plugin is an object of a type of the program's own, derived from Plugin. Instead of being made with a class and name, as an Fl_Plugin is, it is made closed and then opened under a class and a name, and it is taken out of its class by Close or as it is finalized. A Plugin_Manager gives back the Ada object itself, or null for a plugin made in C++ by a loaded library, which has a name but no Ada object.

Open raises Constraint_Error for a class or name that is empty or has a "/" in it, and Program_Error for a name its class has already, which FLTK would keep in one node and remove twice (pofltk 108). Plugin_At and Plugin_Name raise Constraint_Error beyond the last plugin, where FLTK's plugin(int) would make a new, empty group.

A library loaded with Load shares the program's plugins only if the two share one FLTK. A program that links FLTK statically must be linked with -rdynamic, or loading a C++ plugin fails with "undefined symbol: _ZTI9Fl_Plugin".

Load_All is written in Ada: the directory needn't end in "/", the sort reads only the names (pofltk 63), and a directory that can't be listed raises Ada.IO_Exceptions.Name_Error.
