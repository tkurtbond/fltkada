gl.h Binding Map

Back to Index

These are the FLTK drawing helpers from FL/gl.h, for use while an OpenGL window is current (inside a GL_Window Draw, or between Start and Finish). OpenGL itself is not bound; the examples/gl3.ads package used by the OpenGL3 examples imports the few core functions they need.

Package name
gl.h FLTK.Draw.OpenGL

Note:

Each text call (Set_Font, Font_Height, Font_Descent, Width, Draw_Text, Measure) raises Program_Error unless a GL context is there: a shown GL_Window current, or between Start and Finish. Start raises Program_Error unless a shown window is current, and on Wayland raises FLTK.Unsupported_Error, since FLTK 1.4.5's gl_start crashes there whatever is current. Finish raises Program_Error with no Start before it.
