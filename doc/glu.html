Part of the separate library fltkada_glu (fltkada_glu.gpr), built only where pkg-config finds glu, after pofltk's FlGlu. FLTK.GLU binds the part of GLU, OpenGL's utility library, that FLTK's programs use: the view matrices and quadrics. FLTK's FL/glu.h only includes the system's GL/glu.h. The rest of GLU (tessellators, NURBS, mipmaps, project and unproject) is not bound.

Package name
glu.h FLTK.GLU

Note:

Call these where a GL context is current: in a GL window's Draw, or between Draw_Begin and Draw_End. Outside one, they do nothing (test_glu checks this with Mesa). A Quadric is closed (gluDeleteQuadric) by Close or when it is finalized; any call on a closed one but Close and Is_Closed raises Program_Error. Create raises Storage_Error if gluNewQuadric returns null. The counts of slices, stacks and loops are Positive, as pofltk requires. The enumerations replace GLU's GLenum constants, so a value GLU hasn't can't be passed, and a Viewport_Area is a record, so it can't be short of four values.
