void end_job(void);

procedure End_Job
       (This : in out Postscript_File_Device);

For a job given a File_Type, raises File_Write_Error if the PostScript couldn't all be written. The job writes to the file through a stream of the binding's, so that FLTK, which under Pango closes the file it was given on a Cairo error and then writes to it, never touches the File_Type's file (pofltk 101).

FLTK reports any other error only with an alert, which waits for the user: a failed write in a job FLTK opened the file for, or a Cairo error the binding doesn't refuse first (pofltk 102).

Raises File_Open_Error if Output isn't open, or if the binding's stream to the file can't be made. The file stays the program's to close, before or after End_Job (pofltk 101). Raises Constraint_Error for the Media format, which isn't a page size: FLTK would read past its table of them (pofltk 103).
