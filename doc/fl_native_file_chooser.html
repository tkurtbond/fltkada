Package name
Fl_Native_File_Chooser FLTK.Native_File_Choosers

Note:

In Ada, filename indices and filter indices are 1-based, unlike the 0-based filename(int) and filter_value() of the C++ API. Options are combined with "+" and removed with "-", and Includes tests for one.
