Part of the separate library fltkada_cairo (fltkada_cairo.gpr), built only where pkg-config finds cairo, after pofltk's FlCairo. FLTK.Cairo binds the cairo calls FLTK's programs use, and a few as simple. A Cairo_Drawn_Window is a double window whose Draw_Cairo draws on it with cairo, after its box and widgets. It isn't FLTK's Fl_Cairo_Window (FLTK.Widgets.Groups.Windows.Double.Cairo), which only an FLTK built with cairo support has: it draws on any FLTK with X11 or Wayland, and its Forge raises FLTK.Unsupported_Error on one with neither.

cairo.h FLTK.Cairo

Note:

A Context is good only for the Draw_Cairo that was given it. Every call on a Context raises Program_Error unless it is the context of a Draw_Cairo still running: one kept and used later, or one no draw gave, raises. Each draw has a new context, so a cairo error, or a Save without its Restore, lasts that draw alone. A call cairo refuses makes Is_Ok False. Draw_Cairo is called only on the display: on another surface, such as an image surface or a printer, the window shows its widgets without it. An exception raised in Draw_Cairo is raised again once control is back in Ada. A Pattern is closed (cairo_pattern_destroy) by Close or when it is finalized; any call on a closed one but Close and Is_Closed raises Program_Error. Cairo keeps a pattern set as a source, so it may be closed while it is. The enumerations replace cairo's int constants, so a value cairo hasn't can't be passed.
