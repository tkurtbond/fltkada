Fl_Tree Binding Map

Back to Index

A deliberately-scoped subset of the API is bound; see the FLTK.Tree_Items / FLTK.Widgets.Groups.Trees note under "Incomplete APIs" in progress.txt for exactly what's left out, and doc/binding_architecture.md for the design notes. Fl_Tree_Item is covered separately in fl_tree_item.html.

Remove, Clear, Clear_Children and Tree_Items.Replace also make the tree forget the items going as its callback item and its last item clicked, which FLTK keeps, so Callback_Item is null once its item has been removed, even in the callback.
