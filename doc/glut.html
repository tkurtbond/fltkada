glut.H Binding Map

Back to Index

FLTK's GLUT emulation is bound in two packages: FLTK.GLUT holds the glut* functions, which refer to windows and menus by number as GLUT does, and FLTK.Widgets.Groups.Windows.OpenGL.GLUT holds Fl_Glut_Window. Window_Of gives the Glut_Window for a window number, and Current_Window the current one: for a window made with Create_Window or Create_Sub_Window, an object made for it the first time it is asked for. A Glut_Window made with Forge.Create is also a GLUT window and can be made current with Make_Current or Set_Window (Get_Number).

Package name
glut.H FLTK.GLUT
Fl_Glut_Window FLTK.Widgets.Groups.Windows.OpenGL.GLUT

Note:

Glut_Window's Make_Current raises Program_Error if the window is not shown.

Note:

The per-window callback setters, Display_Func to Overlay_Display_Func, raise Program_Error when there is no current window, where FLTK drops the callback. Idle_Func, Timer_Func, Menu_State_Func and Menu_Status_Func are global.

Note:

FLTK indexes its window and menu tables without checking (pofltk 112), so every subprogram given a window or menu number that isn't live raises Constraint_Error. Window_Exists and Menu_Exists say which are. GLUT has 31 window numbers and 31 menu numbers. Making a 32nd window, Glut_Window or menu raises FLTK.Unsupported_Error, since FLTK would give it the 31st's number. Destroy_Window raises Program_Error for a Glut_Window made by a Forge, or one holding such a window. It deletes the windows from the event loop, so a window can destroy itself in its display function, and Hide_Window called while drawing is put off the same way. A menu used as a submenu can't be destroyed or changed. Establish_Overlay and Use_Layer raise Program_Error when the current window isn't shown, and Attach_Menu does for an empty menu. Get (Window_Parent) is 0 when the parent isn't a GLUT window.

Note:

The shapes raise Program_Error without a GL context, as the stroke fonts do, and Constraint_Error for a count outside Shape_Count, 1 to 65_536, since FLTK allocates tables of that size with no limit (F36).

Note:

The bitmap font subprograms, Stroke_Character and Stroke_String raise Program_Error without a GL context (pofltk 111). Bitmap_Character moves the raster position by the character's width, not by the width of the texture FLTK drew (pofltk 135), and draws a character past 127 as Latin-1, where FLTK reads 128 to 159 as CP1252 (F29). Text with no width draws nothing, where FLTK crashes (pofltk 134).

Not Bound
int glut_menu;
Not bound as a variable. Get_Menu and Set_Menu are glutGetMenu and glutSetMenu, which read and set it.
