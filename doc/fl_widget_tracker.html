Package name
Fl_Widget_Tracker FLTK.Widget_Trackers

Note:

A widget stops existing, for its trackers, when its Ada object is finalized, even inside a callback, where FLTK deletes the C++ widget only later with Fl::delete_widget. It also stops existing when FLTK deletes the C++ widget itself, as a group does a child with no Ada object. FLTK registers the address of the tracker's pointer, so the C++ tracker is kept on the heap, where it doesn't move when the Ada object is copied.
