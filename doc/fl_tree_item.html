Items are never constructed directly -- see doc/binding_architecture.md. Values of type Tree_Item are only ever obtained from a Tree (via Add, Find, Root, First, Last, or from another Tree_Item via Child, Parent, Next, Prev). (no Forge)
Only for FLTK.Tree_Items.Custom. Handing the result to the tree with Trees.Add or Tree_Items.Replace makes the tree its owner.
